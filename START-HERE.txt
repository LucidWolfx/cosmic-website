COSMIC WEBSITE + MEMBER PORTAL / V3 BRAND DIRECTION

1. Unzip this package.
2. Open site/index.html to view the public website.
3. Open site/portal-preview.html for the fictional applicant/member/staff preview.
4. Open site/setup.html to edit public branding and destinations.
5. Read docs/GITHUB-HANDOFF.md before uploading to a repository.
6. Read docs/LAUNCH.md before connecting real accounts.

A local HTTP server is recommended for testing. From this package folder:
    python -m http.server 8080 --directory site
Then open:
    http://localhost:8080
